# License names and URLs, as POMs declare them, mapped to SPDX license IDs.
#
# Each line holds an SPDX ID or expression, a tab, and one declared name or URL.
# An alias that starts with http:// or https:// is a URL. A line with an ID alone makes the ID known
# without adding an alias. Names and URLs are normalised before matching, so case,
# punctuation, the URL scheme, "www." and a trailing ".txt" or ".html" do not matter.
#
# GNU license URLs and unversioned GNU names are left out on purpose: they do not say
# whether "only" or "or later" applies, and a wrong ID is worse than none. So are URLs
# of pages that cover two licenses at once, such as GlassFish's CDDL+GPL_1_1.html, and
# license pages of individual projects, such as jsoup.org/license: they name no license,
# and keep their address when the project changes its license. Map those with the
# plugin's licenseMappings parameter instead.
